Tentang Saya

Latar Belakang & Passion di Bidang Game Art

Saya adalah mahasiswa aktif S1 Terapan Teknologi Game di Politeknik Elektronika Negeri Surabaya (PENS) (periode aktif 2025–sekarang). Minat dan fokus utama saya berpusat pada penciptaan aset seni game, meliputi 2D Art, ilustrasi karakter, serta pemodelan objek 3D menggunakan Blender. Saya memiliki komitmen kuat untuk menghadirkan visual yang tidak hanya bernilai estetis, tetapi juga selaras dengan atmosfer gameplay.

Nilai Tambah: Pemahaman Teknis Game Development

Keunggulan utama saya sebagai game artist adalah pemahaman teknis alur game development. Saya memiliki pengetahuan dasar pemrograman (C# & C++), manajemen data MySQL, serta alur kolaborasi Git. Dengan latar belakang ini, saya memahami kebutuhan integrasi sprite, collision box, UV mapping, dan hierarki game engine (Unity & Godot), sehingga dapat berkolaborasi secara mulus dan tanpa hambatan komunikasi bersama rekan programmer di dalam tim.
